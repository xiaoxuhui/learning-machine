# 学习小机器

用输入与正确输出的样本训练真实神经网络，再让它预测新输入。当前版本 1.3.0。

打开 `dist/index.html` 可以离线使用；本地服务地址为 http://127.0.0.1:4319/。

## 操作

- 重置：清空全部样本、参数、轮次、预测和字段，恢复 1 输入、1 输出、自动结构。
- 训练：填写每个输入和正确输出，点击开始学习。同一完整输入向量会更新目标，而不是新增重复样本。
- 计算：填写全部输入，预测全部输出；不改变学习参数。
- 在“小机器的脑袋”中可配置 1～4 个输入、1～4 个输出，手动设置 1～4 隐藏层、每层 1～12 节点，再应用。改变输入输出维度会清空不兼容样本，界面会提前提示；只改变层数或节点则保留样本并重训。

默认开启“机器自动改变形状”。每次训练均实际比较一至四隐藏层的七种网络，每种 600 轮。选误差达标且参数最少者；全部未达标时选误差最低者。机器会自己增加/减少隐藏层或节点，不需要选择层数。简单样本仍可能保持小网络；不为展示动画而强行增加层数。

脑袋下方显示结构决定、原结构到新结构、选择原因、各候选实测误差及最近十次决定。手动层数和节点控件默认隐藏；只有明确关闭自动开关才固定结构，之后可以点击“交还机器决定”，保留现有样本重新比较。图示、函数和映射均来自同一套真实参数。输入输出数量继续用于定义任务数据维度。

“它眼中的规律”下显示每个输出的函数；展开可看完整精度表达式。大型网络使用等价的逐层绑定形式，避免指数级展开。“每一层如何映射”显示归一化、中间层、输出层和还原尺度的实际计算结果。多输入曲线为所选维度的函数切片，其余输入固定于当前代入值，样本点也按固定条件筛选。

每个数范围 -1000～1000，最多 32 个不同输入样本。当前页只使用内存，不保存训练数据；刷新也会清空。预测是近似值，少量样本不能保证学到唯一规律，范围外预测尤其可能不准确。

## 开发与验证

仅运行游戏无需安装依赖。Node.js 20+：

```powershell
node scripts/build.mjs
node --test tests/*.test.cjs
node scripts/serve.mjs
node scripts/test-browser.mjs
```

也可使用 package.json 中同名 npm scripts。浏览器测试依赖固定版本 `@playwright/test` 1.62.1；优先使用本项目安装的依赖，本机缺失时只读复用兄弟项目 `light_game` 的同版本环境。测试运行独立临时服务与隔离浏览器，不操作用户当前游戏。Chromium 缓存需已安装。

结构：`src/model.js` 为独立模型，`src/app.js` 为表单与状态协调，`src/visuals.js` 为真实网络图和函数切片，`dist/` 为构建后的离线文件。测试记录见 `evidence/browser-report.json` 和 `doc/第一版本测试报告.md`。

模型由本机 MIT 项目 turbowarp-neural-network 的梯度下降方法扩展为多层、多输入、多输出矩阵实现。没有云端推理或外部网络请求。
