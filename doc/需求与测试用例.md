# 学习小机器：需求与测试用例

版本 1.4.0，2026-11-02。状态：输入输出数量手动填写，固定任务维度，隐藏结构继续自动变化，待验收。

## 目标与规则

用户新建的数字学习游戏，只有重置、训练、计算三种主要操作。用户已确认：训练时自己提供输入数和正确输出数，机器据此学习；计算时仅提供输入，机器预测输出。

- 训练：每次添加一个 x → y 样本，基于本轮全部样本训练真实的多层神经网络。初始 1–2–1；输入输出维度固定，隐藏层与节点可在计算预算内继续增减，图示来自实际模型。
- 计算：只读使用当前模型，不改变参数、样本或训练次数；没有样本时提示先训练。
- 重置：立即清空样本、轮次、预测、表单和曲线，将参数恢复到初始值，回到训练界面，不额外确认。
- 支持 -1000～1000 的有限数、小数和负数；同一输入再次训练更新其目标，最多 32 个不同输入。
- 预测是近似值。界面说明少量样本和范围外预测的局限。
- 不增加积分、强制关卡和隐藏目标。提供可一键填入而不自动提交的例子。
- 本版状态只在当前页面保留，刷新或重置会清空。无帐号、云端推理或网络依赖。
- 后续明确要求：重置、训练、计算在同一行；在“它眼中的规律”下显示实际输出函数；展示每层映射及数值，支持真实的多层嵌套，不使用固定形状装饰图。
- 自动结构候选为 [2]、[4]、[6]、[4,3]、[6,4]、[8,6,4]、[8,6,4,2]。默认“机器自动决定结构”。每次训练都比较全部七个候选，每个训练 600 轮，不因单层先达标而跳过其他深度。若有归一化 MSE ≤ 0.0001 的候选，选参数数目最少的达标者；否则选误差最低者。同参数量按误差、候选顺序稳定打破平局。计算绝不改变结构。
- 显示真实的加层、减层、增减节点或保持决定，列出原结构、新结构、各候选误差及选择原因，并保留最近 10 次结构决策。不会为了动画强行增加层数。
- 层数和节点由机器默认决定，手动控件只在用户明确关闭自动开关后显示；可一键交还机器决定，同维度保留样本重新比较，重置恢复自动。输入输出维度继续由用户定义，因为它们表示任务数据的形状。
- 1.2 增加显式网络配置：输入数量 1～4、输出数量 1～4；手动隐藏层 1～4，每层节点 1～12，或自动结构。应用同维度的新结构保留样本并重训；改变输入/输出维度清空样本、参数、轮次、预测与表单，应用按钮前明示此行为。完全重置恢复单输入、单输出、自动结构。
- 每个输入和正确输出使用独立标记的数字框；向量输入的完整相等关系决定样本更新。多输出损失按输出维度取平均，缩放按各维独立计算。每个输出都有实际函数，逐层映射显示全部维度。
- 多输入时曲线显示指定输入维度到指定输出维度的切片，其余输入固定于当前代入值；仅显示满足固定条件的样本，避免将高维投影冒充同一条函数曲线。

## 1.4 当前规则（覆盖历史版本的固定上限）

输入/输出数量由用户填写正整数，不设 1～4 的语义上限；分配前按整个网络的参数数目（20,000）和每个候选的训练工作量（30,000,000 参数更新预算）验证，超预算提示并保留当前数据。手动结构也按同样预算验证。自动搜索在每次训练中生成有限候选，包含原基础七种和当前结构的邻近增减，最多十二种；因此不再只在固定七个预设之间切换。自动候选均基于真实训练误差选择，输入输出维度不变。大图超过可读节点数时折叠显示首尾节点，并明确实际数量；参与计算的节点不减少。
