# 学习小机器：需求与测试用例

版本 1.2.0，2026-11-01。状态：已确认监督训练、多层结构与多输入多输出需求，待实现验收。

## 目标与规则

用户新建的数字学习游戏，只有重置、训练、计算三种主要操作。用户已确认：训练时自己提供输入数和正确输出数，机器据此学习；计算时仅提供输入，机器预测输出。

- 训练：每次添加一个 x → y 样本，基于本轮全部样本训练真实的多层神经网络。初始 1–2–1，拟合误差未达阈值时自动尝试更宽或更深的结构，最多三个隐藏层；图示来自实际模型。
- 计算：只读使用当前模型，不改变参数、样本或训练次数；没有样本时提示先训练。
- 重置：立即清空样本、轮次、预测、表单和曲线，将参数恢复到初始值，回到训练界面，不额外确认。
- 支持 -1000～1000 的有限数、小数和负数；同一输入再次训练更新其目标，最多 32 个不同输入。
- 预测是近似值。界面说明少量样本和范围外预测的局限。
- 不增加积分、强制关卡和隐藏目标。提供可一键填入而不自动提交的例子。
- 本版状态只在当前页面保留，刷新或重置会清空。无帐号、云端推理或网络依赖。
- 后续明确要求：重置、训练、计算在同一行；在“它眼中的规律”下显示实际输出函数；展示每层映射及数值，支持真实的多层嵌套，不使用固定形状装饰图。
- 自动结构候选按复杂度为 [2]、[4]、[6]、[4,3]、[6,4]、[8,6,4]、[8,6,4,2]。每个候选 600 轮，归一化均方误差 ≤ 0.0001 时停止；全部不达标则保留误差最低者。自动从小网络开始，明确说明简单样本可能无需加深。计算绝不改变结构。
- 1.2 增加显式网络配置：输入数量 1～4、输出数量 1～4；手动隐藏层 1～4，每层节点 1～12，或自动结构。应用同维度的新结构保留样本并重训；改变输入/输出维度清空样本、参数、轮次、预测与表单，应用按钮前明示此行为。完全重置恢复单输入、单输出、自动结构。
- 每个输入和正确输出使用独立标记的数字框；向量输入的完整相等关系决定样本更新。多输出损失按输出维度取平均，缩放按各维独立计算。每个输出都有实际函数，逐层映射显示全部维度。
- 多输入时曲线显示指定输入维度到指定输出维度的切片，其余输入固定于当前代入值；仅显示满足固定条件的样本，避免将高维投影冒充同一条函数曲线。

## 验收用例

| 编号 | 验收 |
| --- | --- |
| U01 | 初始样本 0、训练 0 轮、预测空态，训练表单可用。 |
| U02 | 提交 1 → 2 后样本 1、轮次至少 600，权重发生变化且损失有限。 |
| U03 | 依次训练 0 → 0、1 → 2、2 → 4，计算 1.5 的预测与 3 相差小于 0.35。 |
| U04 | 计算前后所有权重、样本和训练次数完全相同。 |
| U05 | 相同 x 更新 y，不产生重复样本。 |
| U06 | 重置后所有学习状态、表单与预测均清空，初始权重恢复。 |
| U07 | 空值、无穷、非数字、越界值不改变状态；负数、小数和零可用。 |
| U08 | 第 33 个不同输入被拒绝；32 个样本时仍可更新已有输入。 |
| U09 | 桌面与 390px 移动屏幕无横向溢出；鼠标、触摸、Enter 可操作。 |
| U10 | 示例只填表，不暗中训练；计算模式切换不删除训练成果。 |
| U11 | 网络连线取自实际权重；曲线和样本点取自实际模型及数据。 |
| U12 | 源码构建后的 dist 可离线直接打开，浏览器无脚本异常。 |
| U13 | 三个主操作位于同一行，手机也可见；重置清除结构选择并恢复 1–2–1。 |
| U14 | 函数位于预测曲线下方，系数取自真实模型；逐层映射的结果与最终预测相符。 |
| U15 | 支持 1 / 2 / 3 隐藏层真实反向传播；手动选择多层后真实层数、图示和函数同时改变。 |
| U16 | 自动结构选择根据实测误差决定；未达到目标时明确说明，不保证完美拟合。 |
| U17 | 可配置 1～4 个输入、1～4 个输出和最多 4 个隐藏层，每层节点可单独设定；训练、图示和映射使用真实矩阵维度。 |
| U18 | 二输入二输出学习和/差规则，逐输出预测、公式求值及有限差分梯度一致。 |
| U19 | 多输入任一字段非法时不改变模型；同一向量更新目标，不同向量同首元素不被合并。 |
| U20 | 改变维度清空旧样本，修改同维度层数保留旧样本；重置恢复默认维度和结构，所有字段同步。 |
| U21 | 多维切片横纵轴标签和固定值说明正确；移动视口、长向量和完整函数不溢出。 |
