# 学习小机器：需求与测试用例

版本 1.0.0，2026-10-31。状态：已确认训练规则，待实现验收。

## 目标与规则

用户新建的数字学习游戏，只有重置、训练、计算三种主要操作。用户已确认：训练时自己提供输入数和正确输出数，机器据此学习；计算时仅提供输入，机器预测输出。

- 训练：每次添加一个 x → y 样本，基于本轮全部样本训练真实的 1–6–1 神经网络。调整权重，用连线和曲线显示变化。网络结构固定，采用用户允许的“调整参数”方案。
- 计算：只读使用当前模型，不改变参数、样本或训练次数；没有样本时提示先训练。
- 重置：立即清空样本、轮次、预测、表单和曲线，将参数恢复到初始值，回到训练界面，不额外确认。
- 支持 -1000～1000 的有限数、小数和负数；同一输入再次训练更新其目标，最多 32 个不同输入。
- 预测是近似值。界面说明少量样本和范围外预测的局限。
- 不增加积分、强制关卡和隐藏目标。提供可一键填入而不自动提交的例子。
- 本版状态只在当前页面保留，刷新或重置会清空。无帐号、云端推理或网络依赖。

## 验收用例

| 编号 | 验收 |
| --- | --- |
| U01 | 初始样本 0、训练 0 轮、预测空态，训练表单可用。 |
| U02 | 提交 1 → 2 后样本 1、轮次 600，权重发生变化且损失有限。 |
| U03 | 依次训练 0 → 0、1 → 2、2 → 4，计算 1.5 的预测与 3 相差小于 0.35。 |
| U04 | 计算前后所有权重、样本和训练次数完全相同。 |
| U05 | 相同 x 更新 y，不产生重复样本。 |
| U06 | 重置后所有学习状态、表单与预测均清空，初始权重恢复。 |
| U07 | 空值、无穷、非数字、越界值不改变状态；负数、小数和零可用。 |
| U08 | 第 33 个不同输入被拒绝；32 个样本时仍可更新已有输入。 |
| U09 | 桌面与 390px 移动屏幕无横向溢出；鼠标、触摸、Enter 可操作。 |
| U10 | 示例只填表，不暗中训练；计算模式切换不删除训练成果。 |
| U11 | 网络连线取自实际权重；曲线和样本点取自实际模型及数据。 |
