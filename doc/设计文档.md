# 学习小机器：设计文档

版本 1.2.0，2026-11-01。实施策略：无运行依赖，静态 HTML / CSS / 顺序加载的普通 JS。

## 模块与数学含义

1. src/model.js：纯模型，在本机已有 MIT 项目 turbowarp-neural-network/src/network.mjs 的梯度下降方法上扩展矩阵层数组，支持任意候选的多隐藏层。隐藏层 tanh，输出线性，平方误差和完整反向传播，学习率 0.08，每个候选训练 600 轮。forwardTrace 提供每一层的输入、线性变换与激活；functionExpression 生成完整系数的嵌套函数。
2. src/visuals.js：SVG 网络与预测曲线，无外部图标或字体。真实层数决定列数，实际节点决定纵向排布；权重决定连线颜色、粗细。函数和逐层映射取自相同模型，不另建近似模型。
3. src/app.js：训练/计算表单、结果、样本清单、重置、消息与焦点协调。不暴露伪精度，结果显示六位有效数字。只保留当前页内存状态。
4. index.html / src/styles.css：浅米白、薄荷绿与深墨色实验台。桌面双栏，手机单栏，原生表单和可访问标签；减少动态效果偏好得到尊重。
5. scripts/build.mjs：复制运行所需文件到 dist，提供离线可用入口。scripts/serve.mjs：127.0.0.1:4319 本地预览；测试服务使用随机空闲端口。

## 状态与边界

samples 为 [x,y] 数组。layers 为 {weights: number[][], biases: number[]} 数组，含输出层。训练先验证，再更新样本并重新拟合全部样本，避免归一化范围改变后旧参数失配。自动按 [2]、[4]、[6]、[4,3]、[6,4]、[8,6,4] 尝试，归一化 MSE ≤ 0.0001 即停止；否则选择实测误差最低的候选。可手动选择真实结构以探索深层网络；切换会立即重训已有样本。初始化使用确定性伪随机数，重置恢复自动和 [2]。epochs 累加实际执行轮次，loss 为原始输出单位的均方误差。训练完成后清除旧预测，防止旧模型结果被误读成新结果。

函数采用 h0=x/sx；hl=tanh(Wl·h(l-1)+bl)；f(x)=sy·(Wout·hLast+bout)。短式和每层方程默认显示，完整嵌套展开按需查看。展示舍入到六位有效数字并明示，完整展开保留 JS 数值的全部位数。浏览器验证选择三层后结构、连线数、方程和推理映射同步改变。单元测试用有限差分检验深层解析梯度，避免只测自洽而漏掉错误反向传播。

无需持久化、迁移或服务端接口。32 样本限制保证同步运算负担有限。错误提示使用 aria-live，字段使用 inputmode=decimal；表单使用文本数值输入以统一验证。网络图和曲线具备标题、说明和文字数据替代。

## 1.2 多输入、多输出与四隐藏层

inputSize/outputSize 各 1～4；真实矩阵形状为 [inputSize,...architecture,outputSize]。逐维 inputScales/outputScales 独立归一化。scalar API 在一维时保留返回数字，多维时返回数组；核心运算统一向量。多输出梯度使用 2*(prediction-target)/outputSize，匹配各输出归一化平方误差均值。

configure 在修改前完整验证维度与结构。维度变化清空训练状态，保留用户刚应用的新配置；同维度仅修改结构则保留样本重训。reset 恢复 1 输入、1 输出、auto、[2] 以及全部初始状态。任意错误均先验证，不产生部分变更。

手动结构支持 1～4 层、各层 1～12 个节点，不局限于预设候选。自动候选增加 [8,6,4,2]。网络图根据每层真实节点数绘制，最多六列。完整嵌套表达式有最大展开预算：过大的网络采用完整精度的逐层 let 绑定表达式，保持数学精确并避免指数级文本阻塞页面。

多维表单按数量生成带有 x1/x2/y1/y2 标签的字段。逐层方程含每个归一化输入、所有中间值、全部输出。图表采用明确条件的函数切片，图上只显示与固定输入条件匹配的样本。
