# 学习小机器：设计文档

版本 1.0.0，2026-10-31。实施策略：无运行依赖，静态 HTML / CSS / 顺序加载的普通 JS。

## 模块与数学含义

1. src/model.js：纯模型，复用本机已有 MIT 项目 turbowarp-neural-network/src/network.mjs 的确定性 1–6–1 网络算法，整理为浏览器和 Node 通用接口。隐藏层 tanh，输出线性，平方误差和反向传播，学习率 0.08，每次 600 轮。
2. src/visuals.js：SVG 网络与预测曲线，无外部图标或字体。权重决定连线颜色、粗细；隐藏节点显示归一化输入激活值。绘图数值做有限性检查。
3. src/app.js：训练/计算表单、结果、样本清单、重置、消息与焦点协调。不暴露伪精度，结果显示六位有效数字。只保留当前页内存状态。
4. index.html / src/styles.css：浅米白、薄荷绿与深墨色实验台。桌面双栏，手机单栏，原生表单和可访问标签；减少动态效果偏好得到尊重。
5. scripts/build.mjs：复制运行所需文件到 dist，提供离线可用入口。scripts/serve.mjs：127.0.0.1:4319 本地预览；测试服务使用随机空闲端口。

## 状态与边界

samples 为 [x,y] 数组。训练先验证，再更新样本并重新拟合全部样本，避免归一化范围改变后旧参数失配。重置采用确定性初始参数，便于比较与复现。epochs 为累计执行轮次，loss 为原始输出单位的均方误差。训练完成后清除旧预测，防止旧模型结果被误读成新结果。

无需持久化、迁移或服务端接口。32 样本限制保证同步运算负担有限。错误提示使用 aria-live，字段使用 inputmode=decimal；表单使用文本数值输入以统一验证。网络图和曲线具备标题、说明和文字数据替代。

## 验证

Node 原生测试覆盖真实学习、只读预测、重置、重复输入、上下界、容量及非法值原子性。真实 Chromium 浏览器覆盖训练→预测→重置、键盘、移动触摸与布局；阻断外网，证明独立运行。检查源码与构建产物一致。Sites 尝试私有托管交付；若基础服务不可用，交付可运行本地版本并如实报告。
